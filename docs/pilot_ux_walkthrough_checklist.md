# Pilot UX Walkthrough Checklist

Use this during a trusted pilot dry-run. Record **Pass / Fail / Notes** for each item.

## Setup

| Item | Pass / Fail | Notes |
|---|---|---|
| Confirm app is in internal pilot mode and operator understands this is not lender approval, bank approval, external audit, or SaaS-ready software |  |  |
| Confirm operator knows backend is the source of truth and browser-side JavaScript does not calculate financial outputs |  |  |
| Confirm dry-run will use TUHO and/or Oborovo for trusted pilot checks |  |  |
| Confirm generic solar/wind are exploratory and unvalidated |  |  |
