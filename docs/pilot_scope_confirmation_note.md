# FincoGPT — Pilot Scope Confirmation Note

**Date:** 2026-06-01
**Status:** Internal Controlled Pilot — Not for External Distribution

---

## What is FincoGPT?

FincoGPT is an **internal controlled pilot tool** for structured financial modelling of renewable energy projects (wind and solar).

All calculations are performed by a Python backend engine. Browser-side JavaScript is display-only and does not perform financial calculations.

---

## What is Validated?

The following project paths have been parity-validated against Excel reference workbooks within documented tolerance:

| Project | Capacity | Validation Scope |
|---------|----------|-----------------|
| TUHO Wind (Croatia) | 72 MW | Senior debt, DSCR, SHL, CO2 revenue, equity IRR |
| Oborovo Solar (Croatia) | 53.63 MW | Senior debt, DSCR, SHL, OpEx, equity IRR |

**Tolerance:**
- Senior debt: ±1%
- Equity IRR: ±1.0 percentage point
- Project IRR: ±0.5 percentage point
- Average DSCR: ±0.05

---

## What is NOT Validated

The following are **exploratory and unvalidated** and must not be used as a basis for financial decisions:

- Generic solar projects (no Excel reference)
- Generic wind projects (no Excel reference)
- Generic wind CO2
- Construction IDC (not implemented)
- C.16 Project Rights (not implemented)
- M1-M18 IDC (not implemented)
- Live sculpting / debt re-sizing (not promoted)

---

## Output Disclaimer

- All outputs are generated by the backend Python engine — the browser does not calculate financial results
- Exports reflect the last clean backend run — do not use stale exports
- Always re-run the model after changing inputs before exporting

---

## Claims That Must Never Be Made

FincoGPT outputs must never be represented as:

- ❌ A bank approval or lender approval
- ❌ An external audit certification
- ❌ A certified financial model under any regulatory framework
- ❌ SaaS-ready or enterprise-ready
- ❌ Production-ready under any SLA
- ❌ Compliant with any financial regulation

This tool is an internal pilot. It is not a certified, audited, or externally-approved financial product.
