# Generic Solar / Wind Exploratory Boundary & Demo Guardrail

This file is the **Generic Solar / Wind exploratory
boundary and demo guardrail refresh**. It is the
B-track governance wrapper for the demo / commercial
language after Phase 25B (Phase 24H-2, 24H-3, 24H-4,
25B-1, 25B-2, 25B-2.1, 25B-3).

> **Generic Solar and Generic Wind remain
> exploratory and unvalidated. Generic assumptions
> are illustrative until validated by reference
> models.**
>
> **The B1 no-go claim list, the B11 commercial
> guardrail, the B19 demo claims checklist, the B22
> Q&A matrix, and the B38 UI demo guardrail are the
> primary no-go claim artifacts. B44 is a
> Generic-Solar / Wind-focused refresh that
> supplements the B1 / B11 / B19 / B22 / B38
> guardrails.**

---

## 1. Allowed demo statements

The following statements are allowed in demo /
commercial contexts after Phase 25B. Each statement
is paired with a required caveat.

* **Allowed:** "Generic Solar and Generic Wind
  templates are available."
  **Required caveat:** "Generic Solar and Generic
  Wind are exploratory. Generic assumptions are
  illustrative until validated by reference models."
* **Allowed:** "The Generic Defaults Prefill button
  seeds the canonical reference project defaults
  into a new Generic project."
  **Required caveat:** "The prefill button is internal
  functionality. The defaults are illustrative until
  validated by reference models."
* **Allowed:** "The scenario run loop supports
  edit → save → run for Generic scenarios."
  **Required caveat:** "The scenario run loop is
  internal functionality. It is not model
  validation."
* **Allowed:** "The scenario compare supports 3-way
  and 4-way Generic scenario comparison."
  **Required caveat:** "The scenario compare is
  internal functionality. It does not validate the
  model."
* **Allowed:** "The Multi-Compare Picker is the entry
  point for the multi-compare flow."
  **Required caveat:** "The Multi-Compare Picker is
  UI / navigation only. It does not validate the
  model."
* **Allowed:** "The Generic Export / Download Pack
  is available."
  **Required caveat:** "The export / download pack
  is internal artifact generation. It is not
  bankability."
* **Allowed:** "The What Changed delta indicator
  shows a compact comparison of 10 KPIs across
  runs."
  **Required caveat:** "The What Changed deltas are
  explanatory indicators, not guaranteed accuracy
  claims. The exploratory banner is required for
  Generic Solar / Generic Wind."
* **Allowed:** "The exploratory banner is required
  for Generic Solar / Generic Wind deltas."
  **Required caveat:** "The exploratory banner
  makes it clear that the deltas are not Excel-
  parity validated."

## 2. Prohibited demo statements

The following statements are prohibited in demo /
commercial contexts. Each prohibition is paired with
the no-go claim category that it would violate.

* **Prohibited:** "Excel-parity validated for Generic
  Solar / Wind."
  **No-go claim category:** Generic Excel-parity
  validation claim.
* **Prohibited:** "Bankable" / "lender-ready" /
  "auditable" / "certified" / "regulatory-approved".
  **No-go claim category:** lender / bank / audit /
  certification / regulatory claim.
* **Prohibited:** "Investment advice" / "guaranteed
  returns" / "investor-grade" / "the What Changed
  panel is investment advice".
  **No-go claim category:** investment advice /
  guaranteed returns claim.
* **Prohibited:** "Customer reference" / "production
  customer" / "live customer" / "deployed at [customer
  name]".
  **No-go claim category:** customer reference claim.
* **Prohibited:** "Production-ready" / "enterprise
  SaaS-ready" / "the Generic Modelling / Scenario
  Loop arc is production-ready".
  **No-go claim category:** production readiness /
  enterprise SaaS readiness claim.
* **Prohibited:** "Paid pilot authorized" / "pilot is
  running" / "pilot is approved" / "the Generic
  Modelling arc is approved for paid pilot".
  **No-go claim category:** paid pilot authorization.
* **Prohibited:** "External validation completed" /
  "external reviewer approved" / "audit passed" /
  "Generic Solar / Wind passed external review".
  **No-go claim category:** external validation
  claim.
* **Prohibited:** "The scenario compare validates the
  model" / "the export / download pack validates the
  model" / "the What Changed panel validates the
  model".
  **No-go claim category:** Generic Modelling arc
  overclaim.
* **Prohibited:** "The factory project run summary
  output is external validation."
  **No-go claim category:** factory output
  external-validation claim.

## 3. Green / yellow / red phrasing

The following phasing is recommended for the demo /
commercial language:

* **Green (allowed):** "Internal functionality is
  available" / "the workflow supports X" / "the
  panel is implemented" / "the export is
  available".
* **Yellow (allowed with caveat):** "The defaults
  are illustrative" / "the deltas are explanatory" /
  "the export is internal artifact generation" /
  "the compare does not validate the model".
* **Red (prohibited):** "Validated" / "bankable" /
  "production-ready" / "enterprise SaaS-ready" /
  "Excel-parity validated" / "investment advice" /
  "guaranteed returns" / "customer reference" /
  "paid pilot authorized" / "external validation
  completed".

## 4. Required caveats

The following caveats are required for any demo /
commercial statement that mentions the Generic
Modelling / Scenario Loop arc:

* "Generic Solar and Generic Wind are exploratory
  and unvalidated."
* "Generic assumptions are illustrative until
  validated by reference models."
* "The scenario compare does not validate the model."
* "The export / download pack does not constitute
  bankability."
* "The What Changed deltas are explanatory; they
  are not guaranteed accuracy claims."
* "The exploratory banner is required for Generic
  Solar / Generic Wind."
* "The paid pilot is not authorized."
* "External validation has not occurred."
* "G20 remains BLOCKED."
* "R99 and R102 remain NOT APPROVED."

## 5. Escalation triggers

The following triggers require an immediate
escalation to the user. The B44 guardrail does not
authorize Agent B to act on the escalation; Agent B
flags the escalation to the user.

* Any prohibited demo statement is made in a demo /
  commercial context.
* Any required caveat is missing from an allowed
  statement.
* Generic Solar / Wind is described as "Excel-
  parity validated" or "validated".
* The scenario compare is described as a "model
  validation" or "external validation".
* The export / download pack is described as
  "bankability" or "lender-ready".
* The "What Changed" deltas are described as
  "investment advice" or "guaranteed returns".
* The exploratory banner is missing or removed for
  Generic Solar / Generic Wind.
* The paid pilot is described as "authorized" or
  "running".
* The external review is described as "completed" or
  "approved".
* G20 is described as "promoted" or "approved".
* R99 or R102 is described as "promoted" or
  "approved".

## 8. What must not be claimed

The following must not be claimed in demo /
commercial contexts after Phase 25B:

* Excel parity for Generic Solar / Wind.
* Bankability.
* Lender reliance.
* Audit / certification / regulatory approval.
* Production readiness.
* Enterprise SaaS readiness.
* Investment advice.
* Guaranteed returns.
* Customer reference.
* Paid pilot authorization.
* External validation.
* The scenario compare is a model validation.
* The export / download pack is bankability.
* The What Changed deltas are investment advice or
  guaranteed returns.

## 9. G20 remains BLOCKED

G20 remains BLOCKED. The Generic Modelling /
Scenario Loop arc does not promote G20. G20 is the
gate for the senior debt / loan amortization / cash
sweep; it is unaffected by the Generic Modelling /
Scenario Loop arc.

## 10. R99 / R102 remain NOT APPROVED

R99 (sponsor cashflows double-count fix validation)
and R102 (sponsor distribution handoff contract)
remain NOT APPROVED. The Generic Modelling /
Scenario Loop arc does not promote R99 or R102.

## 11. Generic assumptions are illustrative

The Generic Solar / Wind defaults are **illustrative
until validated by reference models**. The
illustrative status must remain visible in the UI
(the exploratory banner) and in the demo /
commercial language (the required caveats) until the
defaults are validated.

## 12. What B44 is not

* B44 is not a code change. Agent B does not implement
  Generic Modelling code.
* B44 is not a replacement for the B1 / B11 / B19 /
  B22 / B38 no-go claim artifacts.
* B44 is not external validation.
* B44 is not a paid pilot authorization.
* B44 is not a customer reference.
* B44 is not a production readiness claim.
* B44 is not an enterprise SaaS readiness claim.
* B44 is not a financial model validation.
* B44 is not a substitute for the user's demo
  decisions or the user's marketing decisions.
