# Pilot User Script

A short script for a friendly external pilot user to follow during a
first session with Finco One.

1. Create a Standard Solar project — from the project browser, choose
   **New Project**, select **Solar**, and submit with a project name,
   country/market, and capacity.
2. Change capacity / tariff / OPEX — open the project's Inputs area
   and adjust capacity (MW), tariff (EUR/MWh), and OPEX Y1.
3. Run the model — choose **Run** from the workspace.
4. Review IRR / DSCR — check Project IRR, Equity IRR, and DSCR in the
   results summary.
5. Create a Downside scenario — from the Scenarios area, save the
   current inputs as a **Downside** scenario.
6. Compare Base vs Downside — use **Compare** to see the headline
   metric deltas between the two scenarios.
7. Export workbook — from the Export area, download the institutional
   workbook.
8. Read Known Limitations — open the Known Limitations page (footer
   or Help menu) before relying on any of the above for an external
   decision.

See `docs/pilot_readiness_checklist.md` for the underlying checklist,
and `docs/external_pilot_guide.md` for full detail on each step.
