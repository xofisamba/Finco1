# Scenario Compare / Export / Download Evidence Register

This file is the **Scenario Compare / Export /
Download evidence register**. It is the B-track
governance wrapper for the evidence of the Scenario
Compare, Multi-Compare, Export, and Download
workflows.

> **The register distinguishes between internal test
> evidence, manual UX evidence, export artifact
> evidence, external validation evidence, and
> missing evidence. The register does not invent
> evidence.**
>
> **The register is internal governance. It is not
> external validation. It is not a paid pilot
> authorization. It is not a customer reference.**

---

## 1. Evidence categories

The register distinguishes between the following
evidence categories:

* **Internal test evidence:** automated tests that
  pass on main.
* **Manual UX evidence:** manual review by the user
  or the designated reviewer.
* **Export artifact evidence:** the actual export /
  download artifacts generated by the workflow.
* **External validation evidence:** review by an
  external reviewer. **None available at B46
  authoring.**
* **Missing evidence:** evidence that is required but
  not yet collected.
