# Pilot Readiness Checklist

A concise checklist for confirming the core workflow is usable before
inviting a friendly external pilot user.

- [ ] Create project
- [ ] Edit assumptions
- [ ] Save / reopen
- [ ] Run model
- [ ] View KPIs
- [ ] Create scenario
- [ ] Compare scenarios
- [ ] Export workbook
- [ ] Read validation status
- [ ] Read known limitations

Each item should be confirmed against a real project (e.g. a new
Generic Solar project) immediately before a pilot session, not assumed
from a prior pass.

See `docs/pilot_user_script.md` for a step-by-step script a pilot user
can follow directly, and `docs/external_pilot_guide.md` for the full
narrative walkthrough.
