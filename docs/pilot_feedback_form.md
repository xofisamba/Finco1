# Pilot Feedback Form

A structured form for collecting feedback from External Friendly Pilot
users after their session. Copy this into a shared doc, form tool, or
spreadsheet per pilot user. Ratings use a 1-5 scale where noted
(1 = very poor / strongly disagree, 5 = excellent / strongly agree).
