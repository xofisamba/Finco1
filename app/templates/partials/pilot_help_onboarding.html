What is FincoGPTv
FincoGPT is an internal pilot tool for structured financial modelling of renewable energy projects (wind/solar). It computes debt sizing, equity returns, DSCR, and distributions using a Python backend engine.
Validated templates
[Validated] TUHO Wind (72 MW, Croatia) - frozen-template, parity-validated against Excel (senior debt, SHL opening, distributions, CO2 revenue)
[Validated] Oborovo Solar (53.63 MW, Croatia) - frozen-template, parity-validated against Excel
[Warning] Generic / new projects - unvalidated; assumptions and outputs should be reviewed independently before drawing conclusions
Demo / Pilot mode
Pilot mode uses selected validated template projects (TUHO / Oborovo) for trusted internal review. Generic projects are for exploration only unless separately validated.
App is single-user / internal pilot mode - no multi-tenant isolation or RBAC.
How to run a pilot workflow
1. Select project - Choose TUHO or Oborovo template for validated results, or generic for exploration only
2. Review assumptions - Check inputs in the sidebar before running
3. Save scenario - Create a named snapshot before making changes
4. Run model - Backend calculates outputs; JS is display-only
5. Review results - KPIs (IRR, DSCR) and debt/equity panels appear after run
6. Review audit - Audit / Parity tab shows parity evidence against Excel
7. Export - Downloads tab provides XLSX, CSV, and parity workbooks
How to read Audit / Parity
The Audit / Parity tab summarises parity evidence for TUHO and Oborovo. It is internal review tooling, not a certified external audit. Green = within tolerance. Yellow = accepted convention difference. Red = gap.
Senior Debt, SHL Opening, and Distributions are the primary parity anchors. Equity IRR has a +/-1.0pp tolerance; Project IRR has a +/-0.5pp tolerance.
Export / Download
Exports are based on the last clean backend run, not unsaved draft edits. If you changed inputs after the last run, save the scenario and run again before exporting.
Available exports: Values-only Excel, Runtime Summary CSV, Institutional Workbook, Parity Workbook, Gap Register, Source Map.
Backup and Restore
Auto-backup creates a dated copy of the SQLite database every 24 hours (configurable via FINCO_AUTO_BACKUP_INTERVAL_HOURS). Up to 10 auto-backups are retained; manual backups and pre-restore safety backups are not pruned.
To restore: use the documented backup/restore flow and create a safety backup first. This is for single-user internal recovery - no enterprise DR or cloud/offsite backup is implemented.
Limitations and non-claims
[Not included] Not a lender or bank approval - this app does not provide credit analysis or lender approval
[Not included] Not an external audit or certification - the Audit / Parity tab is internal review tooling
[Not included] Not SaaS-ready - single-user internal pilot mode; no multi-tenant isolation or RBAC
[Not included] Not a live sculpting solver - the frozen senior debt schedule is fixture-backed from Excel; it is not a dynamic sculpting calculation
All model outputs are produced by the backend Python engine. Browser-side JS is display-only and does not calculate financial outputs.
